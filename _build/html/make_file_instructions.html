Installing required packages¶

  1. Install sphinx

    pip install sphinx

  1. Install type hints for sphinx

    pip install sphinx-autodoc-typehints

  1. Install myst-parser

    pip install myst-parser

Generating the documentation¶

  1. Method one:

Go to the directory where the file is located and run the following command:

    sphinx-build -b html "/home/cephadrius/Desktop/git/Lexi-BU/lexi/" "/home/cephadrius/Desktop/git/Lexi-BU/lexi/docs/"

This will generate the documentation in the docs folder.

  1. Method two: Go to the directory where the file is located and run the following command:

    make clean
    make html

make clean will remove the existing build files and make html will generate the documentation in the build folder.
